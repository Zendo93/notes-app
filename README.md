# Notes app

Notes App hosted on this GitHub repository combines **Vue.js** for the frontend and **Node.js** or Mocked API for the backend. Create, edit, and delete notes with ease. Find notes quickly using a dynamic search feature and keep things concise with a character limit. Filter notes as needed. A versatile solution for efficient digital note management with a focus on clean and maintainable code.

![Notes app](https://images.squarespace-cdn.com/content/v1/50eca855e4b0939ae8bb12d9/1491603286291-OBWY64NI1EQATK05MCAZ/image-asset.jpeg?format=2500w)

## :hammer: Technologies & Tools

- Vue.js (Vue 3)
- State management (Pinia)
- UI framework (Vuetify)

## :trophy: Required features

- Users can add new notes.
- When adding a new note, users can fill in title, description, and category (including validation).
- Users can see created notes sorted by date.
- Users can edit and delete notes.
- Users can filter notes by category.
- Maximum length of notes is enforced.
- Mocked APIs (e.g. [MockAPI](https://mockapi.io/), [JSON-Server](https://www.npmjs.com/package/json-server) or another solution)
